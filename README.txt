KHALEEQUE AHMED — PORTFOLIO WEBSITE

Files
- index.html : page content and sections
- style.css  : layout, colors, responsiveness, and 3D cube styling
- script.js  : interactive cube controls and mobile navigation

How to run
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Double-click index.html to open it in a browser.

Notes
- The page is built with plain HTML, CSS, and JavaScript.
- Google Fonts require an internet connection; the site still works without them.
- Contact details and project descriptions are based on the CV and screenshots shared by the owner.
- LinkedIn profile URL uses the profile slug supplied by the owner.
